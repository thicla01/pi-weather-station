Design reference · Nearby alerts · display-only overlay

A quiet look-around-me layer over the radar.

A new optional map layer that paints active government weather-alert polygons within a user-set radius. It never notifies — it surveys. Mocked across the four screen classes and the runtime palettes, with the alert-radius ring kept distinct from the radar rings in every mode.

Dock toggle · three states

BottomDock button

Off → on → on with worst-tier count badge

A warning-triangle glyph. Idle uses the quiet dock ink; pressed takes the active accent wash; the badge bubble is coloured to the worst tier present (red > orange > yellow) and disappears at zero. Finger target stays ≥ 44 px throughout.

Tap popups

Single alert

One compact line, one action

Source badge + tier-coloured severity word + title. No description body. A single “Re-center here” button anchors the popup to the tapped polygon.

Compact scroll list, capped at ~40 vh

Overlapping alerts at the tapped spot. One row each — tier left-border, source badge, severity chip, title — sorted worst-first, with a per-row re-center affordance and internal scroll.

Settings · radius slider

Six-stop range slider — drag it to move the hero ring live

Matches the existing Advanced sliders (opacity / brightness). On desktop the Settings panel doesn’t cover the map, so dragging previews the alert-radius ring in real time — shown here driving both the mini-map and the hero shot above.

Palette parity

The same hero · four runtime palettes

The radius ring stays distinct in every mode

Day, dusk and night separate the alert-radius ring from the radar rings by hue — the cool blue, dotted. Night-red can’t use hue, so it keeps the ring red and separates it by a long dash-dot pattern instead. Tiers stay readable against each background throughout.

07

Constraints honoured

i.

The radius ring never reads as a radar ring

In day / dusk / night it’s the cool blue, dotted — clearly not the calm grey radar rings. In nightRed hue can’t differ, so it switches to a long-dot dash-dot pattern instead. Same meaning, no cool hues.

ii.

Co-display stays legible

Polygons sit at ~15 % tier fill so the radar reads straight through; rings are 2 px dashed; precip keeps its blend mode. The 7″ 800×480 case is the binding one — kept clean there first.

iii.

Quiet, touch-first, opt-in

Nothing screams until you turn it on. No :hover backgrounds that stick on touch — pressed / :active states only. Targets ≥ 44 px. Display-only: it surveys, it never notifies.
