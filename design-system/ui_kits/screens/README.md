# Screen kit — Ambient Layers

Six anatomies at real pixel size, composed from the same recipes as the specimen cards (`screens.css` holds the shared component CSS; each screen adds only its layout rules). Radar tiles are a static gradient standing in for RainViewer. Like production (`ui/reset.css`), everything inside `.screen` is `box-sizing: border-box`, so a recipe's `min-height` is the card's outer height.

`LayoutPi` (800–1279 px wide) picks its MID rail by **CSS viewport height**, not by panel: at ≤ 540 px (`priorityViewsEnabled()` in `ui/piLayout.js`) it serves the **v3.3 priority glance**, above it the **v3.2 stacked rail**. The 7″ (800×480) always gets the glance; the 10.1″ (CSS 1024×640) gets the stacked rail. MIN, MAX and the AI view exist on both.

- **pi-7in-glance** — 800×480, **what the 7″ shows in MID**. `LayoutPi` grid `1fr 300px` + dock row, 10 px framed gutters, map as a 14 px card. Map: zoom stack (top 16 / left 16: `ui/reset.css` falls back to a 16 px edge gap and zeroes Leaflet's 10 px control margin), radar-focus square (top 100 / left 16) on the same guide line, the legend as its "(i)" chip (≤ 520 px and MID), **no timeline** — the dock's timeline button opens the scrubber on the fullscreen radar (MIN), so it never reads ON here. Rail (calm): compact clock (date = Saisons trigger, next sun event) · HeroCompact with its ⤢ corner square (opens the Conditions view) and **no feels-like** · NowcastLine with its RADAR badge ("Aucune pluie sur 100 km": the calm line quotes the outer analysis ring, 100 km / 60 mi, even when only the 50 km ring is drawn) · AirCard. No 2×2 and no indoor — they live in the Conditions view. The calm glance leaves ~90 px free: that is the budget of the alert stack (compact AlertBanner card · "restore N hidden" pill · AirAlertCard), which leads the rail when an eligible alert is active. Priority dock, labels hidden (≤ 980 px): Map (recenter · places · marker · timeline · direction arrows · legend ON · nearby alerts) · Views (AI view · forecast) · Display (contrast · auto · night-red moon, always `#c44040`) · System (refresh · settings) · health disc.
- **pi-7in-mid** — the **v3.2 stacked MID rail** that `LayoutPi` serves **above the 540 px CSS-height gate** (the 10.1″ at CSS 1024×640), **drawn at 800×480 for scale** — the 7″ itself never shows it (see pi-7in-glance). Rail order (calm): compact clock · HeroCompact (39 px temperature, feels-like line, no astro line, no ⤢) · NowcastLine · AirCard (Pi tightening) · MetricsGrid 2×2 · Indoor when configured. At 800×480 the stack overflows and the rail scrolls (the grid's second row sits below the fold); the 10.1″ gives the rail ~550 CSS px. Above 520 px of height the map keeps the **full legend card**, re-anchored above the open timeline (bottom 122 px), and the full timeline copy; the timeline is on because `radarTimelineVisible` defaults to true (its dock button reads ON). Dock as on the glance, timeline ON; group labels hide ≤ 980 px (the 10.1″, 1024 px wide, shows them).
- **pi-7in-min** — radar owns the screen: grid collapses to `1fr 0`, no padding, no radius, rail and dock gone; the focus button reads solid accent; the FloatingMiniBanner (top 16 / right 12) keeps an active government alert visible — never blind the user to a warning. Dusk.
- **pi-7in-max** — forecast-forward: map frozen to a `190px` thumbnail, `ChartTabs` in its `slabPiMax` form fills the rail (title hidden, period pills flush left, restore bracket), Hours grid 4 × 2 at a 3-hour step, summary row. The specimen simplifies the Hours tab: in the code, MAX shows 24 cells, 8 × 3 at a 1-hour step, scrolling inside the chart area (4 × 2 / 3-hour is the non-maximized rail form), and the empty summary row collapses on that tab (it shows on Temp / Wind / Precip). Dock hidden. Reached from the dock's Views group, left via the slab's restore button.
- **desktop-1280** — 1280×800 `LayoutDesktop`: full-bleed map (`inset 0 0 52px`), hero band top-left (left 86 = gap + zoom stack, right = rail 320 + 2 gaps), rail 320 (alert head · air · 2×2 · forecast · AI summary), dock 52 with group labels and the health chip. Legend card bottom-left; the timeline anchors above it when both are on. Dusk + `data-hybrid="light"` (a watch is active).
- **mobile-portrait** — 390×844 `LayoutMobile`: one scroll column with 10 px rhythm — clock (56 px) · alert head · HeroCompact (56 px, astro line) · air · 2×2 · radar card 220 px with its 44 px maximize button · forecast · AI. Portrait dock keeps the essentials only (recenter, marker, contrast, refresh, settings, health dot).

Each file links `../../styles.css` and `screens.css`, is tagged `@dsCard group="Screens"`, and uses `sprite.svg` for the glyphs (simplified stand-ins for the Iconify icons the code ships).
