Pi Weather Station — système de design « Ambient Layers »

Langage visuel du kiosque météo v3 (Raspberry Pi 7″ tactile, aussi desktop et PWA mobile), transposé depuis le code : quatre palettes servies à l'exécution (tokens/ + themes/), niveaux hybrides d'alerte, contrat typographique Geist, recette de slab, jetons radar et carte, grammaire à trois viewports et règles kiosque.

Palette par défaut = day. Ajoutez data-theme="dusk", "night" ou "nightRed" et, pendant une alerte, data-hybrid="light|full" sur n'importe quel conteneur. Le code fait foi en cas de désaccord ; la galerie complète vit dans l'onglet « Design System ».
